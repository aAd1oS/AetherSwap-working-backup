## 数据边界

克隆的源码不包含个人账号、成交记录或自定义策略文件。首次启动后才在本机生成自己的运行资料。

数据库、完整配置导出、Cookie、API Key、通知地址、令牌密钥、浏览器会话均不得发给同学或上传 GitHub，即使仓库是私有的。具体排除范围见交付检查。

文档只保留这六个主题入口；一次性的审查留在归档中。不维护重复的“新版教程”，也不在首页堆积历史测试数字。
