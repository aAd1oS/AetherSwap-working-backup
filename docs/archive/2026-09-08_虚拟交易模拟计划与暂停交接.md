## 2. 对话总结与研究目标

用户观察到部分商品上架超过 24 小时仍未售出，希望模拟完整的“筛选 → 买入 → 冷却 → 上架 → 等待 → 成交或滞销”，调查两个方向：

1. **购入时忽略持续下跌：** 七天前的低价可能只是下降趋势中的阶段低点，冷却结束后价格继续走低，原利润目标无法达到。
2. **出售时忽略等待风险：** 达到目标收益而上架不代表能成交；之后价格下降、新挂单和同价竞争可能导致滞销。

最初的历史模拟购入数量偏少，用户要求修正；随后发现“达到上架条件或价格触及”不能回答多久卖出的问题。因此讨论扩展为历史回放与从现在开始的虚拟交易两条路径。用户不希望为了实验实际买商品。

最终确定：**先不改变策略，先把模拟和数据证据做好。** 不为凑满预算放宽策略，不把价格触及当成交，不用其他市场成交冒充 Steam 成交。需要 API、凭据更新或用户操作时立即提出，不擅自退而求其次。

## 3. 实验规则

| 项目 | 已讨论约定及恢复注意事项 |
|---|---|
| 真实交易 | 全程虚拟，不使用真实资金、库存或交易接口 |
| 策略 | 冻结恢复时确认的现有购入策略与参数；不擅自改动 |
| 购入批次 | 连续三天，每天独立预算 |
| 每日预算 | 300 元；累计未达到 300 元时允许最后一件超出预算，达到或超过后停止 |
| 单件上限 | 35 元人民币；计算使用整数分 |
| 同名上限 | 每天同名最多一件，次日可以再次买一件，三天最多三件 |
| 购入时段 | 最初 10:00—14:00，后将旧实验 24—26 日扩展为全天；恢复新实验时重新明确窗口，不直接套用旧日期 |
| 冷却 | 按虚拟购入时间加七天；这是实验假设，不等于所有真实资产的实际解锁规则 |
| 出售 | 同一持仓分别运行现有策略 2、3，建立独立对照分支，不能重复计入同一组合收益 |
| 观察期 | 上架后观察 24、48、72 小时；未走完窗口的样本保留为未完成 |
| 历史回放 | 希望重新运行最近 14 天，弃用旧结果；恢复时重定日期，另取策略所需预热历史 |
| 前向虚拟交易 | 恢复并验收后才确定起点，本次讨论日期不是已经开始购入的时间 |

三天购入、七天冷却、末批再观察 72 小时，需约 13—14 天运行窗口。最近 14 天窗口末尾买入的商品可能尚未解锁，不能强行给出售结论。

## 6. 恢复后的实施路线（尚未执行）

### 第一阶段：隔离与验收

1. 核查工作区和现有自动任务，保留用户未提交修改，不重置、清理或覆盖。
2. 建独立模拟目录，存实验配置、策略快照与源码哈希、原始行情、虚拟账本、报告和测试。
3. 仅只读获取真实业务配置；所有模拟写入使用独立账本。现有部分账户/配置函数可能初始化、迁移数据库，不能直接视为无副作用。
4. 网络白名单只允许所需行情查询；不能只靠 GET/POST 判断安全，因为部分行情也用 POST。真实锁单、付款、买卖、撤单、确认接口全部隔离。
5. 验收候选、BUFF 报价、Steam 深度及历史的时间戳、币种、单位、数量含义、限流和权限。缺失立即停止对应流程并提出所需操作。

### 第二阶段：策略与全流程

1. 复用核查过的纯计算逻辑，冻结配置，不导入会启动真实业务或写真实库的执行链。
2. 保留实际启用的排序、折扣、卖压、清洗、趋势和保护条件；暂不支持的自定义模块阻止启动，不能静默跳过。
3. 实现日预算、同名上限、最后一件超额、冷却、独立策略 2/3 分支与虚拟订单状态。
4. 原始证据和模拟判定分开保存；重复执行、重启和重放不重复买入、卖出或记账。
5. 历史决策只用当时已知数据；快照按真实观察时间使用，不能将小时末数据提前放到小时初。

### 第三阶段：等待与滞销模型

记录挂价与市场价差、同价和更低价数量、销量变化、新增竞争、市场下跌及数据缺口。状态至少区分：冷却中、未获策略批准、已上架、模型估计成交、超过观察期限、数据不足。

可研究保守排队模型、成交时间生存分析及多种成交假设的敏感性分析。尚未成交样本保留为删失数据，不能丢掉；订单消失可能是撤单，不能自动算成交；聚合销量不证明在我方价格发生了交易。

Steam 直接购买、买单匹配、物品差异和跨币种换算均可能影响成交，不能未经验证套证券市场简单 FIFO 规则。即使快照齐全，虚拟成交也是估计，不是复原出的真实成交。

### 第四阶段：测试与实验报告

- 测试：真实接口隔离、未知数据停止、币种与费用、未来数据排除、预算边界、每日去重、冷却、双分支隔离、断线重启恢复、撤单不冒充成交。
- 小批只读验收后才能持续采集；遵守限流，不争抢真实业务网络额度。
- 历史资料通过验收才运行新历史实验，否则保持阻塞，不能将旧结果换名复用。
- 报告包含：候选及拒绝原因、购入金额、冷却后趋势、上架批准比例、24/48/72 小时未成交比例、等待时间、费用后模拟收益、未完成样本和数据覆盖率。
- 分别归因购入时下降趋势与上架后的市场变化；只提出有证据的改进建议，真正改策略需用户另行批准。
