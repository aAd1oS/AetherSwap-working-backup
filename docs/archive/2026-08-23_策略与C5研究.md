# 2026-08-23：策略与 C5 研究

## 研究范围

本轮比较了采购候选、价格口径、持有时间、卖出建议和 C5 市场数据的适用边界。

## 保留结论

- C5 可作为额外的只读价格参考，但字段必须先用真实样本验证。
- 只读比价不等于自动交易接入；购买、支付、报价、出售均不能因出现 C5 数据而自动启用。
- 不同市场的价格可能包含不同手续费、币种、可交易时间和流动性，不能直接按数值排序。
- 稳健统计和趋势指标适合先做展示与影子评估，运行时阻断必须有明确配置契约和回归测试。
- 卖出建议需要考虑持有时长、净价、手续费和成交深度，并对相同建议去重。
- 价格字段含义不明确时应保留“估计”标记，不能通过固定除数制造精确感。
