# 2026-08-19：箱子策略研究与回测

## 研究目的

评估在预算约束下采购多个低价箱子并等待价格或流动性变化的可行性，同时检查策略是否会因为“必须花完”而放大风险。

## 保留结论

- 回测只能描述历史样本，不能保证真实成交和未来收益。
- 低单价不等于低风险；手续费、锁定期、成交深度和账户限制可能吞掉价差。
- 小额、分散、可停止优于强制满仓或追求把预算花完。
- 单件上限、总预算、最大持仓和候选来源上限必须分别约束。
- 缺少币种、费率或成交量时，应跳过而不是补默认值继续交易。
- 策略应先以影子模式或极小真实样本验证字段，再考虑扩大规模。

## 当时限制

历史回测没有证明平台实时成交、最终到账、锁定期结束后的可售状态，也没有覆盖未来 API 字段变化。因此箱子策略未被提升为默认主策略。
