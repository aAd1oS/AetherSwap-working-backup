# AetherSwap 数据安全与备份

本文件说明哪些内容可以备份、哪些只能留在本机，以及如何安全上传私有 GitHub 仓库。

## 1. 数据分类

### 必须保密

以下文件或字段可能提供登录、交易或通知权限：

- `config/credentials.json`
- `config/accounts.json`
- `config/app_config.json`
- `config/playwright_steam/`
- `config/playwright_buff/`
- `config/playwright_tmp/`
- Steam Cookie
- BUFF Cookie
- PushPlus Token
- `shared_secret`
- `identity_secret`
- `.maFile`
- 邮箱授权码
- 代理账号密码

即使 GitHub 仓库设为 Private，也不建议上传这些内容。私有仓库不能代替凭证隔离。

### 本地业务数据

- `config/app.db`：购买记录、订单台账、现价和出售状态。
- `config/app.db-wal`、`config/app.db-shm`：数据库运行时文件。
- `config/exchange_rate.json`：汇率缓存。
- `config/holdings_report_last.json`：持有回报缓存。
- `log/`：运行日志，可能包含订单号、商品名和错误详情。

数据库适合做加密或离线本地备份，但通常不适合进入源码仓库。

### 可重新生成的大目录

- `.venv/`：Python 依赖环境。
- `.playwright/`：Chromium、无头浏览器、FFmpeg 等运行文件。
- `__pycache__/`
- `.pytest_cache/`

这些目录体积大，而且可以通过依赖文件重新安装，不应上传。

### 可上传源码

- `app/`
- `buff/`
- `steam/`
- `steamdt/`
- `utils/`
- `web/`
- `tests/`
- `docs/`
- `run.py`
- `requirements*.txt`
- 启动脚本
- Docker 和项目说明文件

上传前仍要扫描是否误放 Cookie、Token 或 `.maFile`。

## 2. 当前 `.gitignore`

当前仓库已经忽略主要凭证、数据库、日志和虚拟环境，但上传前还应确认至少包含：

```gitignore
config/credentials.json
config/app_config.json
config/accounts.json
config/playwright_steam/
config/playwright_buff/
config/playwright_tmp/
config/app.db*
log/
.venv/
.playwright/
__pycache__/
*.py[cod]
*.maFile
```

如果某个秘密文件在加入 `.gitignore`之前已经被 Git 跟踪，后加忽略规则不会自动从历史中删除。

检查被跟踪文件：

```powershell
git ls-files
```

检查忽略状态：

```powershell
git status --short --ignored
```

## 4. 为什么不上传整个项目目录

整个项目目录包含：

- 数百 MB 的 Playwright 浏览器。
- Python 虚拟环境。
- Steam 和 BUFF 浏览器登录资料。
- 本地数据库和日志。
- 实际账号配置。

上传整个目录会造成仓库巨大、克隆缓慢，并增加凭证泄露风险。即使 Private，也没有必要。

## 5. 上传安全备份到私有 GitHub

在安全 `source-tree`中执行：

```powershell
cd "D:\Vibe Coding\backups\AetherSwap-code-20260806-211845\source-tree"
git init
git branch -M main
git add .
git status --short
git commit -m "Backup working AetherSwap source"
gh auth status
gh repo create AetherSwap-working-backup --private --source . --remote origin --push
```

如果 `gh auth status`显示尚未登录，再执行一次 `gh auth login`，完成浏览器授权后重新运行创建仓库命令。

`gh auth login`交互建议：

1. 选择 `GitHub.com`。
2. 选择 `HTTPS`。
3. 选择浏览器登录。
4. 在浏览器确认授权。

上传前必须检查 `git status`和 `git ls-files`，确认没有 `config/app_config.json`、Cookie、`.maFile`、数据库、日志和浏览器资料。

## 6. 更新私有备份仓库

当前已确认的私有仓库是：

```text
https://github.com/aAd1oS/AetherSwap-working-backup
```

它已经存在且默认分支是 `main`，因此后续不要重复运行 `gh repo create`。推荐从远程仓库克隆一个临时上传工作区，再用最新安全源码树替换其中的已跟踪文件：

```powershell
$source = "D:\Vibe Coding\backups\AetherSwap-code-20260806-211845\source-tree"
$upload = "D:\Vibe Coding\backups\AetherSwap-github-upload-20260806-211845"

gh repo clone aAd1oS/AetherSwap-working-backup $upload
cd $upload

git rm -r --ignore-unmatch .
robocopy $source $upload /E /XD .git
if ($LASTEXITCODE -gt 7) { throw "robocopy 失败，退出码：$LASTEXITCODE" }

git add -A
git status --short
git commit -m "Update AetherSwap working backup 2026-08-06"
git push origin main
```

`git rm`只作用于刚克隆出来的临时上传目录，用来正确记录上个备份中存在、这次已经删除的文件；不会删除真实项目或安全源码备份。运行 `git commit` 前一定先看 `git status --short`，确认没有账号配置、数据库、日志或浏览器资料。

通用更新原则：

1. 从真实项目生成新的过滤后源码树。
2. 对比新旧源码树。
3. 确认排除项仍有效。
4. 在备份仓库提交。

常用 Git 命令：

```powershell
git status
git diff
git add .
git commit -m "Update AetherSwap working backup"
git push
```

不要使用 `git add -f`强行加入被忽略的配置文件。

## 7. 数据库备份

数据库保存真实交易状态，备份前先完全关闭 AetherSwap，确保没有进程继续写入。

需要一起考虑：

- `config/app.db`
- 若仍存在，`config/app.db-wal`
- 若仍存在，`config/app.db-shm`

最简单的方法是在程序完全关闭后复制整个数据库文件到不公开的备份目录。数据库备份不要放进 GitHub 源码仓库。

恢复前：

1. 关闭 AetherSwap。
2. 保留当前数据库副本。
3. 将备份恢复到 `config/app.db`。
4. 启动后检查订单台账、持有饰品和出售状态。
5. 有未决订单时先去 BUFF 和 Steam 平台核对。

## 8. 配置导出与恢复

页面中的配置导出可能包含敏感信息。导出后：

- 只保存在可信本机或加密存储。
- 不发送到聊天或公开网盘。
- 不与源码一起提交。
- 恢复后立即核对账号、策略和通知配置。

## 9. 凭证泄露后的处理

### Steam Cookie 或密钥泄露

- 退出其他设备或撤销会话。
- 修改密码。
- 重新配置 Steam Guard。
- 重新生成项目 Cookie。
- 检查交易报价和市场记录。

### BUFF Cookie 泄露

- 从 BUFF 退出其他会话。
- 修改相关登录凭证。
- 检查购买、出售和资金记录。
- 重新获取 Cookie。

### PushPlus Token 泄露

- 在 PushPlus 撤销或更换 Token。
- 更新本地 AetherSwap 配置。

### GitHub 误提交

仅删除最新文件不等于从 Git 历史删除。应立即撤销凭证，然后再处理 Git 历史；先换密钥，后清历史。

## 10. 提交前安全检查

```powershell
git status --short
git diff --cached --name-only
git ls-files | Select-String "config|cookie|maFile|playwright|app.db|log"
```

还应人工搜索：

```powershell
rg -n -S "steamLoginSecure|identity_secret|shared_secret|pushplus_token|sessionid" . `
  -g "!.git/**" -g "!.venv/**" -g "!.playwright/**"
```

搜索命中配置键名不一定表示泄露；关键是确认值没有出现在文档、测试夹具或提交内容里。
