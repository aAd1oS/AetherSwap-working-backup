# AetherSwap · 个人维护交付版

用于在自己的 Windows 电脑上管理 Steam / BUFF 饰品购买、收货、持仓和出售流程。此仓库是基于原项目持续修改的个人维护版本，面向受邀同学使用，不是原作者的最新发行版。

**交付整理日期：2026-09-27。** “交付版”表示统一了使用入口和维护说明，不表示无故障、无风险或保证收益。当前验证范围与遗留限制见 [维护与验收](docs/05_维护安全与路线图.md)。

## 从这里开始

1. 由仓库所有者邀请你的 GitHub 账号访问本私有仓库，并接受邀请。
2. 按 [安装与日常使用](docs/01_安装与日常使用.md) 克隆、安装、启动，先验收空白页面。
3. 按 [账号配置与首次交易](docs/02_账号配置与首次交易.md) 配置**你自己的**账号；先检查，不启动购买。
4. 理解 [价格、支付与策略](docs/04_价格支付与策略.md)，再决定是否进行一次小额真实交易。

仓库地址：<https://github.com/aAd1oS/AetherSwap-working-backup>。不要克隆旧说明中的 Gitee 或原作者仓库来获取本版本；仓库当前远程内容与本地交付稿可能不同，以维护者交付的提交号为准。

**不要接收或导入维护者的数据库、完整配置、Cookie、令牌或浏览器会话。** 安装完成不等于获得交易授权；“启动购买”会进入真实业务，不是演示。

## 能做什么

- SteamDT 候选筛选、BUFF 报价核查、采购限制及历史价格分析。
- 购入/出售策略配置、模块判定日志与声明式自定义条件。
- 购买订单状态、人工付款核对、收货匹配、账户隔离和持仓跟踪。
- 上架价格展示、出售策略判断、滞销复评，以及可选的分段下架重挂。
- C5 只读比价、通知和辅助行情功能。

支付页面提供支付宝、微信、BUFF 余额及余额优先模式；可用性取决于平台及账号。余额自动扣款需要单独授权，人工点击“已付款”不等于平台确认。新手先关闭自动扣款、自动出售和自动确认。

## 不能承诺什么

- 不保证买到最低价、七天后获利、24 小时内卖出或不受平台限制。
- 策略页“模拟运行”不是完整虚拟交易系统，不能预测真实成交时间。
- 完整历史回放与持续虚拟交易仍 [暂停](docs/archive/2026-09-08_虚拟交易模拟计划与暂停交接.md)，没有作为完成能力交付。
- 本次交付以 Windows、本机回环访问、单实例和单当前账号为范围。多账号记录隔离不等于多个账号并发运行。
- 没有可直接用于公网的完整访问保护；不要做端口映射。现有 Docker 文件保留为开发资料，不作为同学安装入口。

## 使用时最重要的三件事

1. **不要跳过未知状态。** 付款、报价、上架结果不明确时，先核对平台，不重复下单或解除阻断。
2. **关闭窗口不一定退出后台。** 先停止任务、核对未决订单，再在启动终端按 Ctrl+C；详见安装说明。
3. **备份不是交付包。** 完整导出含敏感资料，只能自己保管。交付只发送审核过的源码。

遇到问题时提供时间、操作步骤、错误类型和脱敏截图，不发送完整日志或凭据。先看 [故障排查](docs/03_网络与故障排查.md)；上传与更新由维护者按 [交付检查](docs/06_协作与审查.md) 执行。
